# eagle_alarm
in this project I 'm gonna build an alarm to wake me up but with more features, it include :
_**a clock** 
_ **time counter**
_ **an alarm** (that enables you to play your favorite song to wake you up  )
_ **a touchscreen** and an easy interface  
# THE_BOM (bill_of materials ) :                                                                                   
- esp32 super mini
- 2.8 SPI TFT Touchsceen
- DS3231 (keeps acccurate time without wifi )
- DFPlayer mini
- speaker 3 watt,4 ohm
- 3.7 V lipo battery
- TP4056 charging module
- Capacitive touch sensor (TTP223)
